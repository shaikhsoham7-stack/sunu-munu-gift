# A Tiny Gift for Sunu Munu 💖

A cute, animated mini website for your girlfriend, from her Penguin 🐧.

## What's inside
- `index.html` — the complete gift website with floating hearts, cute animations, and a surprise love letter.
- `make_gift.py` — a tiny Python helper that can launch the site locally in your browser.

## Preview on your computer
You only need Python installed:
```bash
python make_gift.py
```
Then open http://localhost:8000 in your browser.

## Put it online with GitHub Pages (free)
GitHub Pages hosts static websites, so the page itself uses HTML/CSS/JavaScript. The Python helper is only for previewing it locally.

1. Sign in to GitHub and create a **new public repository**, for example `sunu-munu-gift`.
2. Upload `index.html` to the repository's root (you can also upload `README.md`).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show a website URL like `https://YOUR-USERNAME.github.io/sunu-munu-gift/`.
7. Open that URL on your phone to test it, then send the link to her. 💌

Tip: Replace any wording inside `index.html` to make the message even more personal before uploading.
